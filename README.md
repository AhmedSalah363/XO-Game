# XO Game

A Flutter Tic-Tac-Toe game with player selection, timer, score tracking, winner detection, and draw handling.

## Features

- Player selection
- Tic-Tac-Toe gameplay
- Winner detection
- Draw detection
- Game timer
- Win counter
- Play again

## Technologies

- Flutter
- Dart
